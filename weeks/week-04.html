Introduction

This week we build upon our terminal Claude Code CLI dev setup, website redesign experiences, and preliminary exploration of Claude Code CLI fundamentals. In particular, we go deeper into skills and introduce MCP and plug-ins. We go wider with practical concerns of token efficiencies and differentiating between Claude web UI, Cowork desktop app, and our familiar terminal/CLI IDE. Finally, we apply these with lab exercises using more sophisticated web design skills with a real-world application.
